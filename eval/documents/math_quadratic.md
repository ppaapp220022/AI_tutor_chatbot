# 중학교 3학년 수학 학습지 — 2단원 이차방정식: 근의 공식

## 1. 이차방정식의 뜻

등식의 모든 항을 좌변으로 이항하여 정리하였을 때 (x에 대한 이차식) = 0 꼴로 나타나는 방정식을 x에 대한 이차방정식이라고 한다. 일반적으로 이차방정식은 다음과 같이 나타낸다.

ax² + bx + c = 0 (단, a, b, c는 상수, a ≠ 0)

a = 0이면 이차항이 사라져 일차방정식이 되므로, 이차방정식이 되려면 반드시 a ≠ 0이어야 한다. 이차방정식을 참이 되게 하는 x의 값을 이차방정식의 해 또는 근이라 하고, 해를 모두 구하는 것을 이차방정식을 푼다고 한다.

## 2. 지금까지 배운 풀이 방법

- 인수분해를 이용한 풀이: AB = 0이면 A = 0 또는 B = 0이라는 성질을 이용한다.
- 제곱근을 이용한 풀이: x² = k (k ≥ 0) 꼴이면 x = ±√k이다.
- 완전제곱식을 이용한 풀이: (x + p)² = q 꼴로 고친 뒤 제곱근을 이용한다.

인수분해가 쉽게 되지 않는 이차방정식은 완전제곱식을 이용해 풀 수 있다. 이 과정을 일반적인 이차방정식 ax² + bx + c = 0에 적용하여 얻은 공식이 근의 공식이다.

## 3. 근의 공식 유도

ax² + bx + c = 0 (a ≠ 0)의 양변을 a로 나누면

x² + (b/a)x + c/a = 0

상수항을 우변으로 이항하면

x² + (b/a)x = −c/a

양변에 (b/2a)²을 더하면

x² + (b/a)x + (b/2a)² = −c/a + (b/2a)²

좌변을 완전제곱식으로 고치고 우변을 통분하면

(x + b/2a)² = (b² − 4ac) / 4a²

b² − 4ac ≥ 0일 때 제곱근을 이용하면

x + b/2a = ±√(b² − 4ac) / 2a

따라서 다음 근의 공식을 얻는다.

**x = (−b ± √(b² − 4ac)) / 2a (단, b² − 4ac ≥ 0)**

## 4. 판별식

근의 공식에서 근호 안의 식 b² − 4ac의 부호에 따라 근의 개수가 정해진다. 그래서 b² − 4ac를 판별식이라고 부르고 D로 나타낸다.

- D > 0이면 서로 다른 두 근을 가진다.
- D = 0이면 한 근(중근)을 가진다.
- D < 0이면 근이 없다. (중학교 범위에서는 실수인 근이 없다는 뜻이다.)

## 5. 예제

### 예제 1. x² − 5x + 6 = 0을 푸시오.
인수분해하면 (x − 2)(x − 3) = 0이므로 x = 2 또는 x = 3이다. 근의 공식으로 풀어도 a = 1, b = −5, c = 6을 대입하면 x = (5 ± √(25 − 24)) / 2 = (5 ± 1) / 2이므로 같은 답을 얻는다.

### 예제 2. 2x² + 3x − 2 = 0을 푸시오.
a = 2, b = 3, c = −2를 근의 공식에 대입하면
x = (−3 ± √(9 + 16)) / 4 = (−3 ± 5) / 4
따라서 x = 1/2 또는 x = −2이다.

### 예제 3. x² + 4x + 1 = 0을 푸시오.
이 식은 정수 범위에서 인수분해가 되지 않는다. a = 1, b = 4, c = 1을 근의 공식에 대입하면
x = (−4 ± √(16 − 4)) / 2 = (−4 ± √12) / 2 = (−4 ± 2√3) / 2
따라서 x = −2 ± √3이다.
√12 = 2√3으로 근호 안을 간단히 한 뒤 분자와 분모를 2로 약분하는 과정을 빠뜨리지 않도록 주의한다.

### 예제 4. 이차방정식 x² − 6x + k = 0이 중근을 가질 때, 상수 k의 값을 구하시오.
중근을 가지려면 D = 0이어야 하므로 (−6)² − 4 × 1 × k = 0, 36 − 4k = 0, k = 9이다. 이때 방정식은 (x − 3)² = 0이 되어 중근 x = 3을 가진다.

## 6. 근의 공식 (짝수 공식)

일차항의 계수 b가 짝수일 때, 즉 b = 2b′일 때는 다음 공식을 쓰면 계산이 간단해진다.

x = (−b′ ± √(b′² − ac)) / a (단, b′² − ac ≥ 0)

예제 3에 이 공식을 적용하면 b′ = 2이므로 x = −2 ± √(4 − 1) = −2 ± √3으로 같은 결과를 더 빠르게 얻는다.

## 7. 이차방정식의 활용

### 활용 문제. 연속하는 두 자연수의 곱이 72일 때, 두 자연수를 구하시오.
작은 수를 x라 하면 큰 수는 x + 1이다. x(x + 1) = 72, x² + x − 72 = 0, (x + 9)(x − 8) = 0이므로 x = −9 또는 x = 8이다. x는 자연수이므로 x = 8이고, 두 자연수는 8과 9이다.
활용 문제에서는 방정식의 해가 문제의 조건(자연수, 길이는 양수 등)에 맞는지 반드시 확인해야 한다.
